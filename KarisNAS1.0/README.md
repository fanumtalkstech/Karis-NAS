# Karis-NAS 1.0 (Official Release)

Personal Cloud Storage & Media Streaming Portal.

## Quick Start
1. Double-click `install.bat` (or run `python installer.py`).
2. Follow prompts to install at `C:\KarisNAS1.0` (or your custom directory).
3. Access Karis-NAS in your browser at `http://localhost:3251` or `http://<your-ip>:3251`.
